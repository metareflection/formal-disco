Dafny proves termination of recursive functions, methods, and loops via a `decreases` clause whose value strictly decreases on each recursive call/iteration with respect to a well-founded order. Lexicographic tuples (e.g., `decreases m, n`) compare left-to-right. Dafny often infers `decreases` automatically, but writing it explicitly is required for non-obvious cases.

```dafny
function Fib(n: nat): nat
  decreases n
{
  if n < 2 then n else Fib(n - 1) + Fib(n - 2)
}

function Ack(m: nat, n: nat): nat
  decreases m, n
{
  if m == 0 then n + 1
  else if n == 0 then Ack(m - 1, 1)
  else Ack(m - 1, Ack(m, n - 1))
}

method GcdLoop(a: nat, b: nat) returns (g: nat)
  requires a > 0 || b > 0
{
  var x: nat, y: nat := a, b;
  while y != 0
    decreases y
    invariant x > 0 || y > 0
  {
    var t: nat := x % y;
    x := y;
    y := t;
  }
  g := x;
}
```
