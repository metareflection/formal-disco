Lemmas are ghost methods used purely for proof; their body provides hints (e.g., recursive calls, assertions) and their `ensures` clauses become facts the verifier can use at the call site. `twostate lemma` relates two heap states (the state at the start and at the call) and is useful for reasoning about mutations.

```dafny
function Sum(n: nat): nat
{
  if n == 0 then 0 else n + Sum(n - 1)
}

}

method UseLemmas()
{

  assert 2 * Sum(10) == 110;
}
```
