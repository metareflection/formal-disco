`assert(P)` asks the SMT solver to prove `P` at this point. `assert(P) by { ... }` discharges `P` using a local proof block whose intermediate steps are not exported.

```rust
use vstd::prelude::*;

verus! {

fn demo(x: i32, y: i32)
    requires 0 <= x <= 100, 0 <= y <= 100,
{
    assert(x + y >= 0);

    assert(x + y == y + x) by {
        assert(x + y == y + x);
    }
}

} // verus!
```
